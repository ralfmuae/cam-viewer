# cam-viewer
Tool to use alternating/switching several usb cams and display on screen

Useful in Training environments to show things from different cams - the tool can switch hot and cold between cams

Started as my Emeet cams are not able to run with one tool from emeet studio. So this tool can adress both and switch between and give PTZ coords to the emeet pixy cam.
Needs to be adjusted to the actual cam setup in the script. Use the cam-helper.py to determin the available cams in the system and use the numbers in cam-viewer.py
